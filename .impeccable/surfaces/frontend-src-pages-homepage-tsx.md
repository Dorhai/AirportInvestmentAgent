## Direction contract

THESIS: The interface is a dynamic ATFM (Air Traffic Flow Management) Morning Briefing Report. It abandons the generic "chatbot in a bubble" for a structured, document-like analyst workspace where chat generates dense, highly readable data sections.

OWN-WORLD: White/off-white paper-like ground, crisp black ink for typography. Strict 1px hairline rules for structure. Pure functional color coding (amber/red for congestion/warnings, green for opportunity). High-density layout using system sans-serif for prose and monospace for metrics. No soft shadows, no decorative backgrounds, no purple gradients.

STORY: The analyst queries the system in plain English. Instead of a casual chat reply, the system builds a formal, structured intelligence report segment by segment, immediately establishing trust through deterministic data presentation and clear provenance.

FIRST VIEWPORT: A left-aligned or centered conversation column that spans a comfortable reading width (e.g., max-w-4xl). The user's query appears as a simple header. The assistant's response follows, with data components (AirportScoreCard, RankingTable, KpiCard) rendering as crisp, bordered tables or metric grids immediately below the text. The input field sits at the bottom like a command line in a terminal or a simple text area on a report footer. 

FORM: Grounded Candidate 5 (ATFM Morning Briefing Report). Seed key: de80a1d1.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
